# 可扩展动作资源说明

当前 Codex 原生不会分别触发下列创意动作，因此它们不进入 `pet.json` 或官方 11 行图集。后续如渲染器支持自定义事件，可按同一 `192×208` 单元、同一版本的基线/缩放与透明规则制作：

| 扩展动作 | 建议帧数 | 设计 |
| --- | ---: | --- |
| `thinking` | 6 | 歪头、轻微蹙眉、眼睛上移；思考光点必须贴附在皇冠/文件板边缘，不可漂浮 |
| `resting` | 6 | 闭眼、小幅呼吸、头发轻垂；不新增床、枕头或场景 |
| `completed-check` | 6 | 检查文件板、微笑、点头；勾选只作为文件板内的无文字图形并保持贴附 |
| `celebration` | 8 | 轻盈旋转；雪花/星光必须贴附在裙摆或皇冠边缘且硬边不透明 |

当前官方近似映射仍是：`thinking → running`、`resting → idle`、`completed-check → review`、`celebration → jumping`。在 v2 主图集通过前，不生成或安装这些附加行，避免把未触发资源误报为可用状态。
